# Quest journal illustrations

Nine original illustrations generated with QuiverAI Arrow 2 for Lore’s RPG field journal, each with a static light-appearance variant.

| Asset | Purpose |
| --- | --- |
| journal | Field-journal identity |
| expedition-desk | Longer walkthroughs and future editorial uses |
| decision-note | A saved project decision |
| pattern-routes | A reusable convention |
| gotcha-lantern | A lesson from a failure |
| archive-chest | Local project storage |
| messenger-bird | Information sent to a configured provider |
| memory-satchel | Knowledge carried to a later session |
| field-tools | Installing and connecting a client |

The original palette is olive `#A9BD8C`, amber `#E5BA66`, cream `#EDF0DE`.
The `-light.svg` variants use dark olive ink `#456642`, darker amber `#A95A1D`,
and warm paper `#F4EAD1`. They preserve element order and every geometric attribute;
only paint differs. This replaces the earlier global brightness filter.

The chest, bird, satchel and tool roll were generated on 6 November 2026. Quiver
removed stray outer marks from the bird, satchel and tool roll without redesigning
the main objects. Existing card illustrations received the same cleanup earlier.
All artwork remains editable SVG geometry. Exported inline paint styles were
normalized into equivalent presentation attributes before generating light palettes.
There are no scripts, stylesheets, external references, embedded raster images,
account details or private chat identifiers in the shipped assets.

`JournalArt.astro` renders decorative images with explicit dimensions, static named
paths and deployment-base prefixes. CSS selects one appearance, including device
appearance without JavaScript. No Quiver connection is required at runtime.
