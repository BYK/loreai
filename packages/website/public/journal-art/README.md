# Quest journal illustrations

Created with QuiverAI Arrow 2 for Lore's approved quest-journal design.

- `journal.svg`: clothbound notebook, ribbon bookmark, quill, botanical sprig.
- `decision-note.svg`: folded note with a wax seal.
- `pattern-routes.svg`: overlapping route slips with matching branching paths.
- `gotcha-lantern.svg`: travel lantern illuminating an obstacle.

The palette uses olive `#A9BD8C`, amber `#E5BA66`, and cream `#EDF0DE`.
These are static, transparent, geometry-only SVGs. The card artwork received a
focused Quiver cleanup removing stray margin marks while retaining the main
objects and internal detail. No scripts, external references, embedded raster
images, user information, or account metadata are included.

`JournalArt.astro` renders the files as decorative images with explicit dimensions
and deployment-base-aware URLs. `journal.css` adapts their brightness in the light
appearance; files remain editable SVGs and require no Quiver service at runtime.
