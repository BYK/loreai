## Verify recording

<span id="2-install-and-check-the-executable" class="legacy-setup-anchor" aria-hidden="true"></span>

After installation, `lore --version` should print a version. If the command is
missing, open a new terminal and check the installer's printed directory.
[Installation troubleshooting](/docs/troubleshooting/#lore-command-not-found).

Run the selected connection command from your project, then send a normal message.
Open the **Dashboard URL printed by Lore**, select your project, and open
**Sessions**. A recorded conversation confirms that activity reached Lore.

[See verification steps](/docs/first-session/#verify) for the expected result.
Knowledge curation happens later in the background; you do not need a `.lore.md`
entry to verify the connection.

For Codex Desktop, keep the local gateway running, fully quit the Desktop app,
then open it again. Persistent setup saves a backup;
[setup undo](/docs/setup/#undoing-setup) restores settings Lore changed.
For remote gateways or custom providers, see the [setup reference](/docs/setup/)
and [custom upstream guide](/docs/guides/custom-upstreams/).

## Reference

The [installer and uninstall reference](/docs/installation-reference/) lists paths,
configuration effects, runtime options, and cleanup behavior.

### Operational telemetry

Production telemetry is enabled by default. Set `SENTRY_ENABLED=0` before starting
Lore to opt out. [Data, providers, telemetry, and costs](/docs/data-and-costs/).

### What the installer writes

The installer downloads the executable and may update your shell's `PATH`.
[See the full path reference](/docs/installation-reference/#what-the-installer-writes).

### Uninstall

Preview the plan with `lore uninstall --dry-run`.
[Read preservation and cleanup details](/docs/installation-reference/#uninstall).

### Other installation options

With a supported Node.js runtime, run Lore through npm:

```bash
npx @loreai/gateway
```

Node.js 22.16+ in the 22.x line, or Node.js 24+, is required; Node.js 23 is excluded.
This uses Lore's default launch flow. Follow your agent's connection instructions.

### Slimmer installs (remote embeddings)

[Read about optional local runtimes and remote embeddings](/docs/installation-reference/#slimmer-installs-remote-embeddings).

### Existing Conversations

Use `lore import --dry-run` to inspect available sources before importing.
[Read the import guide](/docs/import/).
