* **readStorageMode / setStorageMode: monotonic latch and consistency**: Design principles for vector storage mode abstraction: (1) monotonic latch: once vec0 mode is observed, it NEVER falls back to blob mode — base embedding columns dropped after mode flip ensures no dropped-column reads. (2) setStorageMode consistency: the sticky read latch must agree with what was just written, preventing checkpoint/time-travel disagreements. (3) Callers must never reason about the 2×2 matrix (blob, blob-native, vec0, write-order) — the abstraction hides implementation details. (4) Safe fallback (unrecognized table\_type) must never assume vec0. (5) Resetting the storage mode latch ensures a fresh blob DB is never poisoned by a prior vec0 observation.
