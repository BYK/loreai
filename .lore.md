## Long-term Knowledge

### Architecture

<!-- lore:01a11297-43de-755d-a096-6d5e2e35066a -->
* **Behavioral eval harness: hidden verifier, rot zones, auto-compact baseline, provenance hashing**: Chose a host-side executable verifier over agent-visible tests or an LLM judge because evaluation must measure behavior without leaking expected facts or rewarding plausible prose. Generated facts enter only the initial user turn and are shared by paired arms; the verifier runs outside the workspace, keeps hidden values in its parent, and imports agent code in an environment-scrubbed, network-disabled, read-only child. Report public-contract (\`core\`), current full-contract (\`isolated\`), and cumulative full-contract (\`strict\`) outcomes separately; source scans diagnose provenance but never award points.

<!-- lore:01a12124-92bb-7938-b381-1b97afee7e6a -->
* **buildEmbeddingUnits structural boundaries**: Chose structural \`\n\x1f\` chunk boundaries over parsing \`\[tool:...]\`-looking lines because tool output can contain those strings without starting a new unit. \`buildEmbeddingUnits()\` preserves user text in mixed text/tool rows; \`reduceToolChunk()\` embeds only the tool header and up to 200 characters of its first output line, while full output remains in temporal storage and FTS. Keep \`embedding-units.ts\` dependency-free to avoid an import cycle, and pin producer/consumer separator behavior with a round-trip test.

<!-- lore:01a12109-e463-7637-b977-c895cd70f89b -->
* **Cache-stable LTM deltas, anchors, and disposable token caches**: Use durable tool-pair-safe \[user,assistant] message-tail deltas, not system\[2] rewrites. Freeze the pin baseline and earlier blocks’ bytes and positions; track accumulated id:hash mutations so ranking churn adds nothing, task shifts surface unseen entries, and debounce or the eight-block cap never loses additions. Default debounce inside appendKnowledgePromptDelta. Carry the original task-switch decision into Layer 4; re-anchor resumed deltas only after actual idle recompaction, not a cache-warm skipCompact resume. At coalescing or compaction, rebuild structured mutations from currently project-eligible knowledge and verified live, project-scoped sources—not historical rendered prose; omit unreconstructable legacy text. A later eligible re-share cancels an earlier removal. Re-render debounced edits and preserve frozen blocks outside debounce. Test stored and upstream content after revocation, deletion, re-sharing, and task shifts.

* **Flow chart rendering and inferred-shift rules**: Keep the chronological SVG flow renderer: Sankey charts lose fixed date positions. “Other models” remains one neutral aggregate node, but its hidden models retain separate continuity and transition lanes, with stable provider/family colors; grouping lanes or merging hidden-model transitions can erase continuity or create false self-loops. Place entry marks and hover data on matching predecessor continuity or observed incoming streams when possible, retaining unmatched entries separately. Continuity ribbons are visual cues, not tracked sessions. Timeline sliders share the full-range scale and clamp without crossing; drag-pan preserves the selected duration, and wheel zoom anchors to the pointer’s date. Read only model and timestamp metadata—never prompts or responses. Regression tests cover grouped lanes, colors, entry placement, zoom, pan, and slider clamping.

Run \`entities.ensureSelfEntity()\` before \`entities.forProject()\` so first-person references and relationships have a grounding target; grounding failures remain non-fatal.

Keep response-side \`item\_reference\` coordinates out of wire output and public completed projections. Project and validate lifecycle events for every type in \`PUBLIC\_RESPONSES\_OUTPUT\_ITEM\_TYPES\`, including hosted-tool events, or narrow that allowlist.

* **Embedding pipeline: scheduling, workers, chunk storage, GC**: Embedding scheduling, validation, ranking, and vector GC: Backfills measure byte length with length(CAST(content AS BLOB)) because SQLite TEXT length stops at NUL. GC pages canonical keys on a read worker and guarded-deletes only returned keys. Jobs must be parameterized and structured-cloneable; timed-out workers are retired and cursors preserved.
