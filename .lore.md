* **readStorageMode / setStorageMode: monotonic latch and consistency**: Design principles for vector storage mode abstraction: (1) monotonic latch: once vec0 mode is observed, it NEVER falls back to blob mode — base embedding columns dropped after mode flip ensures no dropped-column reads.
