### Architecture

* **Behavioral eval harness: hidden verifier, rot zones, auto-compact baseline, provenance hashing**: Chose a host-side executable verifier over agent-visible tests or an LLM judge because evaluation must measure behavior without leaking expected facts or rewarding plausible prose. Generated facts enter only the initial user turn and are shared by paired arms; the verifier runs outside the workspace, keeps hidden values in its parent, and imports agent code in an environment-scrubbed, network-disabled, read-only child. Report public-contract (\`core\`), current full-contract (\`isolated\`), and cumulative full-contract (\`strict\`) outcomes separately; source scans diagnose provenance but never award points.

* **chatMessageWithTextProvenance: provenanceContent must copy, never alias content**: Invariant stated by Halil Kayer (restated 11+ sessions): \`provenanceContent\` must never alias \`content\` at construction — copy it (\`provenanceContent: \[...content]\` in \`chatMessageWithTextProvenance\`). Sharing the array looks like cheap synchronization, but provenance mutators (replaceVisibleContentBlock, truncateVisibleContent, removeVisibleContentBlock, insertVisibleContentBlocks, insertCompanionBundle) rewrite one side independently; an alias lets a visible-text rewrite silently corrupt the opaque provenance replayed upstream (marker/anchor leak). Copy-on-write \`withReplacedText\` and the \`detachAliasedProvenance\` guards assume this construction-time isolation. Related replay-fidelity rules: \[\[01a102a2-9fcc-7730-8ddc-b00b76cae1f4]].

* **distilledPrefixCached freezes prefix bytes while prompt cache warm**: Warm cache hit returns the byte-identical cached prefix even when new gen-0 distillation rows were appended — re-rendering messages\[1] near the prompt front would bust the warm Anthropic prompt cache, so new rows stay unrendered until a cold boundary (idle resume / test reset) clears prefixCache. The EMPTY prefix is also pinned (rowCount 0) so a first gen-0 arrival mid-warm-cache cannot inject synthetic messages\[0/1]; onIdleResume clears the empty pin. Full re-render only on first call or meta-distillation rewrite. loadDistillationsCached keys rows by lastUserMessageId (turn boundary, shared with prewarm) to keep prefix bytes stable during tool-call chains. Same cache-stability family as \[\[01a0a451-bd6b-7b75-8c59-8d73f7159484]].

* **loreai principle: 'Your AI never starts over' — no lossy summary**: Halil Kayer-stated product principle for loreai (restated 6+ sessions): 'Your AI never starts over' — sessions stay coherent for days and millions of tokens, with no lossy summary. * **recall provenance mutators: copy-on-write, never mutate caller-parsed objects**: The user consistently enforces immutability invariants in the recall/provenance pipeline. Parsed caller objects (messages, content blocks, Responses envelopes) must never be mutated in place — always produce replacement copies (e.g., withReplacedText, {...block, raw: {...raw, text}}), and raw.text must stay in sync with visible text. Unknown or protocol-native metadata must be preserved verbatim as opaque blocks and round-trip losslessly, never projected into visible text or mutated. When editing this codebase, follow copy-on-write for every provenance-aware mutation, guard against array aliasing, keep envelope fields untouched, and state these invariants in doc comments. Surface violations for user decision before changing code.

* **gradient.ts bust-spiral alerting: sub-cap layer-0 sessions never alert, spiral is upstream canary**: Halil Kayer-stated policy (Nov 13 2026): sessions at layer 0 + tier 0 (sub-cap) must NEVER raise bust-spiral alerts — their busts come from structural causes (e.g. prompt-delta position drift after post-idle recompression), not genuine context growth.
