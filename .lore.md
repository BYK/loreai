## Long-term Knowledge

### Architecture

<!-- lore:01a08126-4de0-7a17-acbb-36db061a13de -->
* **#1711 Responses ingress boundary**: Chose streaming only \`/v1/responses\` and \`/v1/codex/responses\` over converting every JSON ingress route, because their shared OpenAI item normalizer can process \`input\` incrementally. Anthropic, Chat, Gemini, and compaction routes require distinct full-protocol parsing or intentionally retain exact body text for fallback replay. This reduces compressed/decoded/raw-tree peak allocations, but deliberately does not solve #1710’s post-parse full-history semantic replay: normalized \`GatewayRequest.messages\` are still complete.

<!-- lore:01a08daf-ae7e-72a6-89bb-2c59d44753ab -->
* **Assistant tool\_result exclusion**: Assistant responses must never contain \`tool\_result\`; tool results belong to user-side request/replay messages. Treating translated provider blocks uniformly looks simpler, but emits an invalid role/content pairing and can break downstream protocol consumers.

<!-- lore:01a08ccd-212f-77d1-a448-f1c3ceb8f73c -->
* **Billing header system\[0]**: The authoritative billing header is always \`req.system\[0]\`: Claude Code emits it there and the worker prepends it. Chose positional authority over content searching because copied billing-header text can appear elsewhere, but a copy can never occupy offset zero; scanning content risks treating user-controlled duplicates as authoritative.

<!-- lore:01a08d30-7d77-76fc-a430-a38e228e60a5 -->
* **buildProjectKnowledgeCatalog exact IDs**: Project knowledge catalogs must say that Lore knows what project knowledge exists and can recall it. Preserve full canonical \`k:\`/\`xk:\` IDs because \`recallById\` uses exact \`ltm.get(id)\` lookup; shortened IDs look cleaner but cannot resolve. Never suggest tombstoned entries for recall, because removed knowledge must not be surfaced as available context. Every revision of the Lore framing note starts with the bracketed \`Lore\` leading substring.

<!-- lore:01a042a2-c9cb-7776-a9ac-26a0fd3ad24c -->
* **Client-controlled project metadata is never authoritative**: Hosted request directories and client headers are untrusted. Hosted mode must never read \<directory>/.lore.json because a client-controlled file could alter gateway budgets, models, or thresholds; use trusted server configuration instead. Likewise, resolveTrustedRemote must treat the on-disk Git remote as authoritative. A stale or forged x-lore-git-remote header may not override disk truth or select another repository. In local mode, discard the client remote when no disk remote exists rather than promoting it to fallback authority.

<!-- lore:01a03650-2683-7c63-a472-1bb84c8d8d67 -->
* **Consolidation opposing-rule invariant**: Consolidation never creates entries, never merges opposing rules, never deletes contradictions, never double-fires, and never busts the v45 prefix. Chose curator \`update\`/\`delete\` application with cooldowns over creating replacement entries or treating contradiction detection as deduplication, because opposing rules require user resolution and new entries can cause recreation/thrashing.

<!-- lore:01a03427-8813-7df7-8d2a-78d13cbdd483 -->
* **Conversation cache layout, TTL, and LTM pin invariants**: Use the 1h conversation-cache TTL; 5m causes avoidable churn. The distilled prefix always occupies transformed-array positions \[0,1], durable knowledge deltas stay near the tail, and orphan removal never touches the prefix. Meta passthrough bypasses buildAnthropicRequest and remains uncached. Persisted ltmCacheText must equal ltmPinText across restart and re-pin; the pin is baseline-only metadata and is never sent upstream. ltm.forSession() must not bust system\[2] when the selected entry set is unchanged, except for byte-identical re-anchoring. Moving deltas forward, caching passthrough, or independently rendering cache and pin text destabilizes cached bytes and can cause prefix drift or cache spirals.

<!-- lore:01a0909d-4a16-77aa-9500-e35d3b5bacd5 -->

A single fluctuation looks sufficient to justify \`5m\`, but changing TTL alters cached bytes and shortens the idle boundary, compounding cache busts. Evaluate \`auto\` only after five samples; reset the downgrade streak on promotion or nonqualifying turns.
