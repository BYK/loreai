Get started

Your first session

The first milestone is a recorded session, visible in Lore’s local app. You do not need to wait for a knowledge file to check the connection.

Verify

Section titled “Verify”

Select the client you connected on the install page, then check its recorded conversation. Earlier install and connection instructions are available below the checklist if you need them. This website cannot detect your local gateway.

  1. 1Install
  2. 2Connect
  3. 3Verify
Choose your coding agent
  1. Send a normal project-related message in Claude Code. For a disposable example: “This service should reject duplicate webhook deliveries by event ID.”
  2. Open the Dashboard URL printed by Lore. Use the actual printed address and port; the local memory browser is separate from withlore.ai.
  3. Select your project in the project picker, then open Sessions.
  4. Open the recorded session. Check that your message appears in its conversation.

Your observation is checked. Next, open the session and inspect its recorded messages.

This checklist does not inspect your local gateway or mark setup complete automatically.

Need the earlier install or connection steps?

If lore --version is unavailable, install Lore first. Have Claude Code installed and authenticated. Run these commands from the project you want to record.

Connect Claude Code

Run this from your project. Lore launches your installed Claude Code client with routing for this session.

lore run claude

Connect Codex Desktop

Configure routing once, start the local gateway, then fully quit and reopen Codex Desktop. Setup backs up the settings it changes.

  1. Configure routing once.
    lore setup codex

  2. Start the local gateway.
    lore start --bg --local

  3. Restart Codex Desktop. Save your work, fully quit the app, then reopen it so it reads the routing settings.
  4. Verify recording. Open your project and send a message in a new conversation. Undo routing changes if needed.

Connect Pi

First add npm:@loreai/pi@latest to the packages array in Pi’s settings.json. The @loreai/pi extension handles routing and memory hooks; pi install installs the configured extension.

pi install
lore run pi

Hermes guide

Model requests use your configured providers and can incur charges. Local Lore runs on your machine; model-provider billing is separate. Production telemetry is on by default; set SENTRY_ENABLED=0 before starting Lore to opt out. Data and costs

Expected result: a project and recorded conversation. A running process or saved routing configuration alone does not confirm that your agent is sending through Lore. If the project or message is missing, follow connection troubleshooting.

Knowledge comes later

Section titled “Knowledge comes later”

Lore distills older conversation and curates durable knowledge in the background. One message does not guarantee a .lore.md entry. Continue normal work, then open Knowledge to inspect what was extracted. How history and knowledge differ.

Review, then reuse

Section titled “Review, then reuse”

Open a knowledge entry and read Source & history. Correct inaccurate content with Edit. Check the .lore.md diff before committing it. A later session can use eligible project knowledge and search earlier details; the supplied context depends on relevance, confidence, scope, and budget.
