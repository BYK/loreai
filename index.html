Before you install

A few practical questions.

Do I need a different coding agent?

No. Lore supports existing clients including Claude Code, Codex, OpenCode, Pi, and Hermes. Follow the guide for your client; desktop apps and terminal launchers have different setup paths. Choose your setup.

Where does my data go?

Memory is stored locally in SQLite and Markdown. Agent requests and Lore’s background LLM work use your configured providers. Production builds send privacy-filtered operational telemetry, which you can disable. Read the telemetry and storage details.

Will a knowledge file appear after one message?

Not necessarily. Distillation and curation run in the background and depend on available conversation and configuration. Check recorded sessions in the local browser first, then review any knowledge Lore extracts. Follow the knowledge checklist.

Does local Lore include live team sync?

Git-based knowledge sharing is available today. Folk Lore’s hosted team experience is in early access; you can join its interest list on the Why Lore page. It does not enable sync.
