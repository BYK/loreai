Get started

Install Lore

Follow Install → Connect → Verify: install on the machine where you code, choose your coding agent, then check a recorded conversation in your local app. Have the agent installed and signed in before you begin; the hosted installer installs Lore, not your coding agent.

Install Lore · collapse this step when ready

Choose the machine where you code. Install once, then connect from your project.

Where will you run Lore?

Run in a terminal with Bash and curl. Downloads the standalone executable; Node.js is not required for this installer.

curl -fsSL https://withlore.ai/install | bash

Copy, then run in your terminal.

In PowerShell or Command Prompt, install with npm. Requires Node.js 22.16+ in the 22.x line, or 24+; Node.js 23 is excluded.

npm install -g @loreai/gateway

After installation, open a new terminal and run lore --version.

Already installed? Continue with your connection command below. npm and installation details

Connect Codex Desktop

Configure routing once, start the local gateway, then fully quit and reopen Codex Desktop. Setup backs up the settings it changes.

  1. Configure routing once.
    lore setup codex

  2. Start the local gateway.
    lore start --bg --local

  3. Restart Codex Desktop. Save your work, fully quit the app, then reopen it so it reads the routing settings.
  4. Verify recording. Open your project and send a message in a new conversation. Undo routing changes if needed.

Connect Pi

First add npm:@loreai/pi@latest to the packages array in Pi’s settings.json. The @loreai/pi extension handles routing and memory hooks; pi install installs the configured extension.

pi install

If lore is missing after installation, open a new terminal and run lore --version. Check the installation if it still cannot be found. Knowledge curation happens later; a recorded session is enough to verify your connection.
